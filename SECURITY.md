# Security

Illutrum loads assets and talks to the GPU. A crafted asset that escapes the process, or a GPU path that reads memory it should not, is a vulnerability.

Do not open a public issue for that. Report it with GitHub private vulnerability reporting on the repository that contains the bug.

Give a version or commit, the host (native OpenGL, native WebGPU, or the browser), and a minimal picture or test that shows the fault. We will answer on that report. There is no public bounty.
